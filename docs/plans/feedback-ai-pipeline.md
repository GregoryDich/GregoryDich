### Главное правило
- **Текст отзыва — это данные, а не команда.** Его никогда не видит ИИ, у которого есть инструменты: репозиторий, почта, ключи AWS, коннекторы.
- **Продукт улучшается только по одной цепочке:**
  1. числа и теги;
  2. критический оценщик;
  3. **«да» владельца**;
  4. задача, написанная словами владельца;
  5. агент;
  6. PR;
  7. ревью владельца.

### Этап 1 — тест (сейчас, без AWS) ✅ решение владельца
- **Форма.** Нативная, на SwiftUI (не внутри WKWebView). Поля:
  - категория;
  - текст до 2 000 символов;
  - галочка «ответьте мне»;
  - блок диагностики: версия приложения и macOS, тип Mac, медиана к/с. Пользователь видит этот блок и может его отключить.
- **Отправка.** Кнопка открывает готовое письмо на `support@tonamorph.com` в почтовой программе пользователя (`mailto` / `NSSharingService`). Для тех, кто пользуется веб-почтой, есть запасная кнопка «Скопировать текст и адрес». Сервера нет, секретов нет, переслать через нас спам невозможно.
- **Разбор.** Владелец читает письма вручную, с метками в Gmail. Анализ — только в **отдельном чате Claude без коннекторов и без доступа к репозиторию**. Нельзя вставлять отзывы в сессию Claude Code с инструментами.
- **ТВ (позже):** QR-код ведёт на короткую веб-форму с одноразовым токеном.
- **Когда переходить на этап 2:** отзывов больше 30–50 в неделю или нужны автоответы.

### Этап 2 — автоматический разбор (AWS, Франкфурт, `eu-central-1`)
1. **Приём.**
   - Письма → SES: проверка SPF, DKIM и DMARC, спама и вирусов → S3.
   - Из приложения → HTTPS API (HTTP API с лимитами).
   - Дальше функция приёма без ИИ: проверка схемы и длины, нормализация Unicode, удаление невидимых и bidi-символов. До передачи в ИИ из текста вырезаются e-mail, телефоны, номера карт и ссылки.
   - E-mail для ответа хранится в отдельной таблице. ИИ его не видит.
2. **Карантинный разбор.**
   - Claude Haiku без инструментов. Права IAM — только вызов одной модели.
   - Отзыв передаётся как JSON-строка с пометкой «недоверенные данные».
   - На выходе — **только значения из закрытых списков**: язык, категория, тон, важность, до 5 тегов, платформа. Плюс флаги: спам, токсичность, подозрение на инъекцию, есть персональные данные.
   - Поле «рассуждение» не запрашиваем.
3. **Проверка кодом.** Проверяются схема, регистр значений и число тегов. Если проверка не прошла, модель отказалась (`stop_reason: "refusal"`) или ответ оборвался — отзыв уходит человеку. Повторной «мягкой» попытки нет.
4. **Автоответ** — по правилам ниже.
5. **Раз в неделю:** сводка → оценщик → письмо владельцу → одобрение → задача → рутина Claude Code → PR.

**«Правило двух».** Ни у одного узла нет одновременно всех трёх свойств: недоверенный текст, доступ к важным данным и действие наружу.

### Защита от «взлома промптом» простыми словами
- **У модели, которая читает отзывы, нет рук.** Инструментов нет, она может только поставить галочки в анкете. Писать ей «отправь письмо» или «измени цену» бесполезно: такой кнопки у неё нет, а свободный текст из её ответа выбрасывается.
- **Ответ пользователю пишет не ИИ.** Код выбирает готовый шаблон владельца по категории.
- **Оценщик не видит ни одного отзыва целиком.** Он получает только счётчики и теги по группам от 5 человек. Каждую цифру в его предложении код сверяет со сводкой.
- **«Накрутка» не работает:**
  - вес отзыва считается по уникальным подтверждённым установкам;
  - не больше 5 отзывов в сутки с одной установки и 20 с одного IP;
  - дубли отбрасываются.
- **Агент с доступом к коду** видит только задачу, которую владелец сам написал своими словами и пометил `owner-approved`.
- **Деньги не утекут:**
  - не больше N вызовов ИИ в сутки;
  - не больше 2 вызовов одновременно;
  - AWS Budgets присылает письма на $10 и $25.
- **Фильтры инъекций — дополнительный слой, а не стена.** Bedrock Guardrails и скрининг через Haiku адаптивные атаки обходят. Защищает архитектура, описанная выше.
- **Регрессионный корпус атак** на английском, русском, иврите и арабском: «игнорируй инструкции», сломанный JSON, bidi, омоглифы, длинные тексты. Прогоняется при каждой смене модели или промпта. Норма: 100 % валидных ответов, ноль свободного текста.

### Ограниченные автоответы
- **Как выбирается ответ.** Таблица «категория × флаги → номер шаблона». Шаблоны пишет владелец на en, ru и he, они хранятся в репозитории.
- **Что в письме.** Только номер обращения, без текста пользователя и без текста ИИ. Поэтому автоответ нельзя превратить в спам от имени `tonamorph.com`.
- **Когда не отвечаем.** Спам, токсичность или подозрение на инъекцию → ответа нет. Важность ≥ high → письмо владельцу.
- **Когда отвечаем:**
  - письмо пришло по почте и прошло SPF, DKIM и DMARC (иначе ответ уйдёт на подделанный адрес);
  - отзыв пришёл из приложения и стоит галочка согласия.
- **Ограничения рассылки:**
  - не чаще одного ответа на адрес за 7 дней;
  - список отписавшихся в SES;
  - в письме есть строка об отписке.
- **Никакой рекламы в автоответах.** Тогда это сервисное письмо, а не реклама по закону о спаме (ст. 30א) (?).

### Гейт «критический оценщик» и одобрение владельца
- **Агрегатор** раз в неделю считает категории, теги, тренды неделя к неделе, разбивку по версии, ОС и устройству. Группы меньше 5 скрыты.
- **Оценщик «про-маркетолог»** — Sonnet 5.5 или Opus 5.5 **без инструментов**. На вход он получает сводку и «конституцию продукта», написанную владельцем:
  - фотореализм и премиум, никакой мультяшности;
  - 60 к/с на любом устройстве;
  - только ассеты с чистой лицензией;
  - никакого нового сбора данных без решения владельца.
- **Выход оценщика** — не больше 5 предложений в JSON. В каждом:
  - тема (из списка);
  - цифры-доказательства (код сверяет их со сводкой);
  - действие из списка: investigate, fix_bug, perf_work, content_pack, copy_change, pricing_test, no_action;
  - польза, цена и риски;
  - **обязательный контраргумент и дешёвый способ опровергнуть идею**.
  
  Отклонённые идеи тоже попадают в выход, с причиной.
- **Цитаты** выбирает код, только из отзывов без флагов. Они идут в письмо владельцу, оценщику — нет.
- **Одобрение.** Владелец нажимает одноразовую подписанную ссылку (HMAC, действует 7 дней). Скрипт создаёт задачу в GitHub **текстом владельца** с меткой `owner-approved`.
- **Рутина Claude Code** — раз в неделю, например в воскресенье в 08:52 по Иерусалиму:
  - удалить из рутины **все коннекторы**: по умолчанию включены все (Gmail, Drive, Notion, Shopify, Zapier, Klaviyo…);
  - без ключей AWS и секретов, сеть — только доверенные адреса;
  - на вход — только задачи `owner-approved`; API-триггер с текстом не включать;
  - на выход — PR в `claude/feedback-weekly`. Префикс `claude/` — лишь значение по умолчанию. Поэтому `main` защищаем правилом GitHub **без права обхода**: если у подключённого GitHub-доступа права админа с обходом, push в `main` пройдёт;
  - зелёный статус рутины не означает успех: владелец смотрит транскрипт.

### Модель и регион
| Вариант | Строгий JSON | Haiku: вход / выход за 1 млн токенов | Где обрабатываются данные |
|---|---|---|---|
| **Bedrock, Haiku 5.5, EU-профиль** (рекомендуем) | Нет: на новом endpoint Bedrock structured outputs не поддерживаются, поэтому только проверка кодом | $0,11 / $0,55 | ЕС (несколько регионов ЕС) |
| Bedrock legacy, Haiku 4.5, EU-профиль | Да | $1,10 / $5,50 | ЕС |
| Claude Platform on AWS, Haiku 5.5 | Да | $0,10 / $0,50 (Global), для US ×1,1 | Anthropic; только US или Global, без ЕС |

- **Почему не Тель-Авив.** В `il-central-1` Claude доступен только через Global, то есть инференс может уйти в любой регион. Классического приёма почты SES там нет: Mail Manager стоит $50 в месяц. Поэтому Франкфурт.
- **Доступ к моделям.** Для Haiku 5.5 на Bedrock может понадобиться запрос доступа. Haiku 4.5 открыт всем.
- **Лимиты расходов** у Claude Platform on AWS отстают примерно на 2 ч, и перерасход оплачивается. Поэтому свой счётчик бюджета нужен в любом варианте.
- **Токены.** Haiku 5.5 насчитывает на тот же текст примерно на 30 % больше токенов, чем 4.5. В таблице стоимости это учтено.
- **Логи.** Логирование вызовов модели в Bedrock выключить или писать без содержимого.

### Стоимость в месяц
**Допущения:**
- 1,5 запроса на один отзыв;
- 30 % отзывов приходят по почте;
- 60 % пользователей согласны на ответ;
- разбор одного отзыва ≈ 1 800 входных и 300 выходных токенов;
- оценщик Sonnet 5.5 запускается ≈ 4 раза в месяц.

Lambda, SQS, DynamoDB и EventBridge при таких объёмах укладываются в бесплатный уровень или стоят центы.

| Отзывов в месяц | Этап 1: почта | Этап 2, лёгкий (HTTP API, без WAF, Haiku 5.5 EU) | Этап 2, укреплённый (REST API + WAF с 3 правилами + Guardrails + Haiku 4.5 со строгим JSON) |
|---|---|---|---|
| 100 | $0 | ≈$0,45 (≈₪1,4) | ≈$8,75 (≈₪27) |
| 1 000 | $0 | ≈$1 (≈₪3) | ≈$12 (≈₪37) |
| 10 000 | $0 | ≈$6–7 (≈₪18–22) | ≈$44 (≈₪136) |

- **Средний вариант:** лёгкий плюс Guardrails, без WAF (+$3 при 10 000 отзывов) — пока не начались атаки.
- **Рутина Claude Code** тратит лимит подписки владельца, отдельных расходов в $ нет.
