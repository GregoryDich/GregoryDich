# 🗺️ JARVIS — роадмап

**Цель проекта одной строкой:** привести пользователя к точке финансовой
безубыточности — пассивный доход ≥ базовые месячные расходы (правило 4%), —
дав ему персональный терминал уровня Bloomberg/Aladdin на бесплатных данных.

> Все рекомендации JARVIS — прогнозы и аналитика, не инвестиционный совет.
> Решения принимает человек; брокерских write-ключей нет по дизайну.

## Фаза 2 — Мозг и персонализация ⬜

1. ⬜ **AI Copilot** (`AI`): Claude Agent SDK с tool-use над DuckDB — чат
   «почему портфель упал?», генерация графиков, объяснение алертов
2. ⬜ NL-скринер: запрос на русском → SQL по локальной базе
3. ⬜ **Навигатор аллокации** (`NAV`) — фирменный экран:
   - движок скоринга каналов: исторические частоты исходов →
     P(рост/флэт/падение) на горизонте, фундаментал + теханализ
   - модель издержек: комиссии IBKR / израильских брокеров, спреды,
     налог 25% на прирост капитала
   - транши ~$1000 только по каналам из профиля пользователя
   - рекомендации по хранению валюты (₪ / $ / €)
4. ⬜ Ticker Deep-Dive (`FA`): SEC EDGAR XBRL (edgartools) — отчётность 10+ лет,
   инсайдерские сделки, 13F, композитные ранги value/momentum/quality
5. ⬜ Скринер (`EQS`): ночная сборка DuckDB фундаментала, сохранённые скрины
6. ⬜ Календарь (`CAL`): эконом-релизы (факт/прогноз/сюрприз), отчётности,
   дивиденды, заседания ФРС/ЕЦБ/Банка Израиля
7. ⬜ LLM-дайджест на русском вместо текстового мини-дайджеста
8. ⬜ Самоулучшение S1–S3, S7 ([SELF_IMPROVEMENT.md](SELF_IMPROVEMENT.md)):
   журнал прогнозов + калибровка Brier, контрфактический P&L против «просто VT»,
   издержки по факту сделок, трекер дисциплины взносов
- **Критерий:** копайлот отвечает на 10 эталонных вопросов по данным;
  NAV выдаёт транши с обоснованием и дисклеймером; каждый прогноз NAV
  записан до исхода и будет автоматически сверен с фактом

## Фаза 3 — Нарративы и социальный сигнал ⬜ (уникальное преимущество)

## Журнал решений

| # | Решение | Почему |
|---|---|---|
| D1 | Композиция компонентов вместо адаптации OpenBB UI | Открытый Terminal UI мёртв (AGPL Platform + закрытый Workspace); Fincept уходит в платную версию |
| D2 | Демо-режим с явной пометкой вместо «тихих» заглушек | Честность данных — ценность продукта; синтетика не должна выдаваться за рынок |
| D3 | Двойной канал алертов (Telegram + ntfy) | Пользователь опасается угона Telegram-аккаунта — потеря одного канала не отключает уведомления |
| D4 | Никаких брокерских write-ключей | Только аналитика и рекомендации; исполнение сделок — вручную человеком |
| D5 | Текущий дизайн остаётся; DESIGN_PROMPT.md — запасная опция | Пользователь: «оставим твой»; полировка своими силами с референсами и вариантами |
| D6 | Атомарный execute+fetch в DuckDB (RLock) | Result set живёт на соединении: параллельные запросы FastAPI подменяли результаты друг друга |
| D7 | Самоулучшение через измеримые петли обратной связи ([SELF_IMPROVEMENT.md](SELF_IMPROVEMENT.md)) | Система обязана измерять собственный вклад в рост состояния (калибровка прогнозов, контрфактический P&L), а не «становиться умнее вообще»; полномочия не растит, сделки не исполняет |

## Риски

- **Лимиты free-tier API** → обязательный кэш (requests-cache), фолбэки,
  честная деградация; апгрейд-путь EODHD $19.99/мес
- **Хрупкость yfinance** (неофициальный API Yahoo) → Stooq-фолбэк, демо-режим
- **Лимит расходов Claude-аккаунта** (упирались в Фазе 0) → экономная
  архитектура ИИ-слоя: FinBERT локально для массовых задач, LLM — точечно
- **Публичный репозиторий** → профиль/портфель/ключи только в gitignored
  `data/` и `.env`; проверка перед каждым коммитом
