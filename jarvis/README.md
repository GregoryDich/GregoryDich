# ⚡ JARVIS — персональный экономический менеджер

Личный финансовый терминал в духе Bloomberg/Aladdin, собранный для одного человека:
многоэкранный тёмный интерфейс, бесплатные данные, риск-аналитика и главный экран —
**точка финансовой безубыточности** (пассивный доход ≥ базовые расходы, правило 4%).

> Всё, что показывает JARVIS — аналитика и прогнозы, **не инвестиционный совет**.
> Исполнение сделок не автоматизируется, брокерских write-ключей нет по дизайну.

## Экраны (Фаза 1 — MVP)

| Мнемоника | Экран | Что показывает |
|---|---|---|
| `FIRE` | Свобода | цель по правилу 4%, прогресс, пассивный доход vs расходы, сценарии «взнос × доходность» |
| `WEI` | Рынки | индексы, USD/ILS, крипто, товары, теплокарта акций, свечные графики, вотчлист |
| `PORT` | Портфель | позиции (метод средней цены), P&L в $ и ₪, VaR/CVaR, Sharpe, β, просадка, кривая капитала |
| `ECO` | Макро | FRED (ставки, инфляция, безработица), спред 10Y−2Y, ставка Банка Израиля, USD/ILS |
| `ALRT` | Алерты | ценовые пороги → Telegram **+ резервный ntfy**, утренний дайджест |

`⌘K` / `Ctrl+K` — палитра команд с мнемониками. Первый запуск — онбординг-мастер:
несколько вопросов (страна, расходы, капитал, каналы) → терминал настраивается под вас.

## Быстрый старт (локально, MacBook)

```bash
cd jarvis
cp .env.example .env          # заполни токены по желанию — без них тоже работает

# Backend
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --port 8000

# Frontend (второй терминал)
cd ../frontend
npm install && npm run dev    # http://localhost:5173
```

Или одним контейнером: `docker compose up --build` → http://localhost:8000
(бот Telegram: `docker compose --profile bot up`).

## Данные: live → фолбэк → демо

| Источник | Что даёт | Ключ |
|---|---|---|
| Yahoo Finance (yfinance) | котировки/история: акции, индексы, FX, крипто, TASE (.TA) | нет |
| Stooq | EOD-фолбэк | нет |
| FRED | макро США (без ключа через fredgraph.csv) | опционально |
| Bank of Israel SDMX | курс USD/ILS, ставка | нет |
| Frankfurter | FX-кроссы | нет |
| CoinGecko | крипто | нет |

Если источник недоступен, JARVIS честно помечает данные бейджем **ДЕМО-ДАННЫЕ**
(детерминированная синтетика) — интерфейс всегда живой, цифры не выдаются за рыночные.

Запуск в облачной песочнице Claude: добавь в network egress allowlist —
`query1.finance.yahoo.com`, `query2.finance.yahoo.com`, `stooq.com`,
`fred.stlouisfed.org`, `edge.boi.gov.il`, `api.frankfurter.dev`,
`api.coingecko.com`.

## Алерты и дайджест

- Порог цены (`выше/ниже`) проверяется каждые 5 минут; утренний дайджест — 07:30 Asia/Jerusalem.
- Доставка через Apprise сразу в **два канала**: Telegram и ntfy-топик.
  Потеря Telegram-аккаунта не отключает уведомления — ntfy остаётся.
- Тест: экран `ALRT` → «Тест доставки».

## Приватность

Репозиторий публичный, поэтому весь личный слой живёт в gitignored-файлах:
`data/` (DuckDB, кэш), `data/profile.local.yaml` (профиль), `.env` (ключи).
В git попадает только код.

## Тесты

```bash
cd backend && .venv/bin/python -m pytest tests -q   # 26 тестов: FIRE, риск, портфель, API
cd frontend && npm run build                         # типы + сборка
```
