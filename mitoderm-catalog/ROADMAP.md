## Порядок внутри страницы средства (образец — EXO-NAD)
1. Раскадровка: сцены, тексты, ограничения, опоры (настоящее фото упаковки), цена.
2. Опорный кадр с людьми → показать заказчику (новый образ) → остальные кадры с этим кадром в опорах.
3. Черновые ролики (Seedance 480p, Kling 1080p) → финалы 1080p после «утверждаю».
4. Сборка фильма со стыками, версия для телефона, подключение движка, проверка в браузере.

## Правила производства
- Один косметолог и одна пациентка на всю страницу; опорный кадр прикладывается к каждому запросу.
- Упаковка сверяется с настоящим фото в каждом кадре; мелкий текст на упаковке читать вплотную.
- Текст на экране — только HTML поверх ролика; в кадрах нет добавленных надписей.
- Сначала один образец нового образа или приёма, потом серия.
- Каждая платная партия сразу записывается в `PROGRESS.md`: номера заданий, цена, остаток бюджета.

## Чего не хватает от заказчика
- Текст на настоящей коробке V-TECH (состав набора).
- Вход для тестовой площадки (Cloudflare) либо публикация через Codex.
- Данные для страницы «Конфиденциальность»: юридическое лицо, срок хранения, дата обновления.
- Список деталей из 3D-страниц, которые нужно перенести.
