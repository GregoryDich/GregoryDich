## Перечень нужных кадров — очередь задаёт ROADMAP.md

Это перечень сцен, не порядок запуска: после текущей проверки SPRAY сначала открывание NAD,
затем точечные планы процедуры. Каждый новый приём проверяется отдельно, без пакетного запуска.

1. **Капля на коже.** Первый тест — статичный крупный план по `IMG_9793.JPG`, с сохранением лица,
   чёрной повязки и фактуры кожи. Первый кадр будущего клипа: маленькая капля на безыгольном
   наконечнике над щекой. Последний: та же капля касается кожи. Никакой тянущейся нити, прокола,
   изменения кожи или выдуманного флакона. Боковой мягкий свет; лицо и рука внутри мобильной зоны.
2. **Подготовка пилинга.** Золотой флакон из оригинала: закрытый до встряхивания → тот же флакон после.
   Затем отдельное читаемое отмеривание; 1 мл — суммарно на лицо, не размер отдельной капли.
3. **Выдержка.** Та же пациентка и нанесённый пилинг; переход времени с живой подписью «15 минут».
   Не ускорять реальный таймер и не изображать мгновенное удаление пигментации.
4. **Нейтрализатор → синий флакон.** Средний план сменяется деталями флакона/руки; последовательность
   не теряется. Убрать салфетку из нового монтажа; без дополнительных придуманных действий.
5. **Упаковка.** Новый `pack-slide-preview`: закрытый верх → сдвиг вдоль коробки →
   читаемые 1+5+5. v2.2 с перпендикулярным подъёмом отклонена. Не заказывать платную генерацию
   механики, пока локальный аниматик не принят.
