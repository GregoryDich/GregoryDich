## Что делаем

Новый файл сценариев v3 для 13 страниц средств и главной (иврит, PDF + DOCX, как файл 01/11 и 06/11). Каждая страница —
короткий фильм в кабинете косметолога, который идёт кадрами по прокрутке. Он ведёт зрителя-косметолога по лестнице
Бена Ханта: от «не знаю продукт» до доверия и заявки. Отдельно — промпты для генерации (английский, рабочий файл) и
дорожная карта.

## Решения (мои, как сценариста; на «ок» заказчика)

**Д1. Зритель — косметолог** или владелец клиники в Израиле (B2B). Герой фильма тоже косметолог, и зритель узнаёт себя.
Финал фильма: «ты можешь быть этим косметологом».

**Д2. Две линии.**
- Лестница Ханта, пять ступеней:
  1. нет проблемы;
  2. знаю проблему;
  3. знаю виды решений;
  4. знаю продукт;
  5. готов к сделке.
- Дуга любви: любопытство → открытие → «вау» → доверие (настоящий кейс) → желание → действие (заявка) →
  принадлежность (семья MITODERM, мероприятия).
- Один блок страницы — одна ступень, один шаг вверх. Кнопка заявки видна с первого блока, для тех, кто уже на ступени 5:
  - на телефоне — закреплённая полоса снизу;
  - на компьютере — кнопка в шапке;
  - короткая форма в выдвижной панели: имя, телефон, «я…» (косметолог / владелец клиники / врач / другое), продукт
    подставлен; есть WhatsApp.

**Д3. Маршрут по сайту.**
- **Главная, блок 1.** Как сейчас: 3D-упаковка висит в воздухе и движется с прокруткой.
- **Выбор средства.** Два пути, на нижних ступенях выбирают по проблеме:
  - по проблеме клиентов: волосы, тусклая кожа, рельеф и рубцы, восстановление после процедур, приборы;
  - по названию средства.
- **Ролик-переход.** Проигрывается 2–4 с одним дублем: наша 3D-упаковка выбранного средства летит, вращаясь, в
  кабинет и ложится на стол косметолога. Это первый кадр страницы средства.
- **Страница средства.** Дальше вниз — только это средство:
  - фильм кадрами по прокрутке и блоки по ступеням;
  - доказательство, оффер, семья и мероприятия;
  - внизу информация о средстве, ссылка на протоколы.
- Протоколов в фильме нет.

**Д4. Грамматика фильма средства (≈30–40 с, кадры по прокрутке).**

| Время | Ступень | Что в кадре |
|---|---|---|
| 0–3 с | 1 | Упаковка (продолжение с главной), название. |
| 3–7 с | 2 | Клиент в кресле, его забота — бережно, в зеркале. |
| 7–11 с | — | Средство прилетает, вращаясь, и ложится на стол. |
| 11–16 с | 3 | Косметолог открывает; фактура крупно, только реальная механика; лицо «вау». |
| 16–22 с | 4 | Ритуал нанесения на свою зону (лицо или кожа головы — по главному эффекту): руки, крупные планы. |
| 22–27 с | Доказательство | Настоящие фото «до/после» шторкой, подпись «после N процедур · результаты индивидуальны». |
| 27–31 с | Радость | Клиент видит себя, улыбается; косметолог гордится. |
| 31–35 с | 5 | «Ты можешь быть этим косметологом» → оффер и форма; семья MITODERM, мероприятия. |

**Д5. Честность.**
- Результат — только настоящие фото «до/после» MITODERM, с согласием клиента. ИИ показывает ритуал и эмоцию, но не
  рисует результат: косметолог распознаёт подделку сразу, а закон о рекламе это запрещает.
- Если фото нет, переход идёт от ритуала к радости, без «результата»: в файле — «нужно от MITODERM».
- Свойства средств — только из утверждённых текстов (каталог, страницы, `source-texts.md`).
- Новые фразы на экране — помечены «הצעה — לאישור».
- Цены, скидки, условия и даты мероприятий не придумываем: даём виды офферов на выбор заказчику.
- Люди, созданные ИИ, — инсценировка. Перед публикацией рекомендуем юридическую проверку утверждений и «до/после».

**Д6. Против «мультяшности».**
- Упаковку никогда не генерируем из текста. Источники:
  - первый и последний кадр — наши HD-рендеры three.js и пакшоты;
  - замена предмета в готовом ролике по нашим пакшотам (Higgsfield Genjutsu «replace object»);
  - крупные планы упаковки — рендер нашей сцены.
- Кабинет и люди — фотореалистичная модель image-to-video, от утверждённых фотореалистичных стиллов, а не от 3D.
- Язык камеры: «shot on cinema camera, 35mm, natural window light, real skin texture, film grain». Без слов
  render / 3D / CGI.
- Короткие планы (2–5 с). Руки и профиль чаще, чем долгие крупные лица.
- Одна цветокоррекция на всю линейку, зерно, апскейл.
- Покадровая проверка: печать на упаковке, пальцы, «пластиковая» кожа, физика. Брак не идёт на сайт.

**Д7. Производство.**
1. Стиллы: кабинет, косметолог, клиент. Плюс наша упаковка, вклеенная в кадр по свету.
2. «Ок» заказчика на кастинг и стиль.
3. Черновики 480p.
4. Выбор.
5. Финал 1080p/4K.
6. Пост.
7. Кадры WebP по ярусам (компьютер 16:9, телефон 9:16 — кадрируется отдельно) — в фильм по прокрутке.

Текст — HTML поверх видео (Rubik, затемнение под текстом), а не буквы генератора. Без JS и при reduced motion — HD-стилл
каждого блока.

**Д8. Лимиты.**
- Higgsfield: на счету 1 кредит (бесплатный план), генерировать не на что, нужна оплата заказчиком.
- Перед каждой генерацией — цена и баланс, трата только после «утверждаю».
- Сначала образец (EXO-NAD — пример самого заказчика: косметолог наносит на лицо), потом серия.
- Сначала образец страницы с фильмом, потом остальные.
- Каждый план, скорее всего, придётся генерировать 2–4 раза: бюджет ×3.
- Фото людей не в git.
- Перезапуски контейнера — шаги ≤ 30 мин, исходники в репозитории.

### Что ускоряю и улучшаю (уже делаю или делаю следующим шагом)

1. **Сборщик файла готовлю параллельно с последними главами**, а не после: адаптация сборщика v2.1 и пробная сборка
   идут сейчас на 12 готовых главах; финальная сборка — пересборка за 3 минуты. Выигрыш ~30 минут.
2. **Один проход проверки вместо двух.** Главы уже прошли редакторов; после сведения — только чтение отрендеренных
   страниц (RTL, обрезки, цифры, покрытие запроса), без второго полного вычитывания. Экономия ≈0,4 млн токенов.
3. **Модели по задаче.** Fable — только основная сессия (решения, ответы заказчику). Писатели и редакторы — Opus.
   Сборки, замеры, проверки по значениям — Sonnet. Ни один агент не читает репозиторий целиком: в промпте — точные
   файлы и ключи.
4. **Без интерактивных вызовов MCP в агентах** (два зависания по 2 часа за ночь): список моделей и баланс снимаю сам
   один раз и кладу в файл; цены — с веба. Записано в скил.
5. **Перезапуски не стоят часов:** номера прогонов в PLAN, `progress.jsonl` у каждого агента, снимки в git каждые
   10–20 минут, `resumeFromRunId`.
6. **Кредиты.** Упаковка во всех планах — наш рендер three.js (0 кредитов): полёт на стол, крупные планы, кадры
   «до/после» упаковки. Люди и кабинет — одна библиотека из ~40 кадров на всю серию (кастинг и сет генерируются один
   раз, экономия 7 кадров на фильм). Черновики 480p (3 кр/с) → финал 1080p только для выбранных дублей. Телефон 9:16 —
   кадрированием там, где композиция позволяет (×1 вместо ×1,6). Для серии — запрос в Higgsfield на корпоративный
   тариф или та же работа через API (Seedance 1080p ≈0,6 $/с), иначе ~17 месяцев тарифа Ultra.
7. **Карта страницы вместо кадров** (сделано): проверка страницы — 2 минуты числами вместо часов рендера; кадры
   рисуем только там, где числа нашли подозрение, и для финального взгляда на 4 экрана.
8. **Один писатель на файл, одна правка на все находки** — без чередования «правка — проверка — правка».
9. **Материалы заранее.** Чтобы гейт 3 не задерживал: список для MITODERM (фото «до/после», согласия, офферы,
   мероприятия, тариф) уходит вместе с файлом, одним списком, по-ивритски.
