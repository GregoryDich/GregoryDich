Правило: текст заказчика — канон. Менялись только очевидные ошибки (описки, сокращения,
диапазоны чисел, названия средств по каталогу, мусорные символы/пробелы, единый формат заголовков).

источника и результата — расходятся только слова из таблицы ниже.
