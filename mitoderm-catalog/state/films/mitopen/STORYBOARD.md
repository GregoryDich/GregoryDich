## Замысел
MITOPEN — перо для микронидлинга: «מסלול החדירה לרכיבים הפעילים.». Фильм — один визит в клинику: перо лежит на
лотке → косметолог осматривает зоны лица и решает, где какая глубина → перо крупно (кольцо, кнопка) → рука
косметолога рядом с пером → **взгляд «внутрь кожи»: ровный ряд временных микроканалов, по ним уходит средство** →
перо → консультация. Главный герой — настоящий прибор; всё, чего нет на настоящих фото, в кадр не попадает.

## Дома или в клинике
Только клиника: «לשימוש מקצועי בלבד»; «שני המכשירים מופעלים בידי אנשי מקצוע שעברו הכשרה, כחלק מפרוטוקול קליני».
Работает косметолог; домашней части в фильме нет.

## Состав и место
- Косметолог **M**: белая форма с розовым кантом, кулон, белые перчатки.
- Пациент **P2** (мужчина): на щеках следы воспалений — показание для работы прибором. Одна одежда во всех кадрах.
- Кабинет — тот же, что в других фильмах. На переднем плане — край стола с чистым белым лотком.

## Ролики и бесплатные переходы
| Что | Из кадра в кадр | Как |
|---|---|---|
| фокус с пера на людей и обратно | K0 ↔ K1 | бесплатно: наплыв `fade` (один и тот же кадр, меняется только фокус) |
| подход к перу | K0 → K2 | бесплатно: плавное увеличение кадра |
| D1 | K1 → Y1 | **платный ролик:** камера уходит в кожу щеки |
| BL | Y1 → Y2 | **платный ролик:** средство уходит по каналам |
| выход из кожи | Y2 → K0 | бесплатно: мягкий расфокус `blur` |
| рука у пера | K2 → K3 | бесплатно: наплыв |

Порядок: K0 → K1 → K0 → K2 → K3 → K1 → D1 → BL → K0 → K1. Около 800 кадров, 33 с, 8 глав.

## Чего не хватает (список — в `PAGES.md`, раздел MITOPEN)
Главное для фильма: **фото или короткое видео пера в руке косметолога у кожи** (лицо и кожа головы) — тогда главы
04 и 05 получат настоящую работу прибором; фото картриджа, зарядки и коробки; исходное фото пера в большем
размере. Без них фильм идёт так, как описано выше: перо только на лотке.
