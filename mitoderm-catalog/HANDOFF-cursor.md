## Как работать быстро и дёшево
- Модели: Sonnet — сборки, замеры, проверки, рутина; Opus — иврит и решения. Fable не нужен.
- Один агент — один файл. Сначала образец, потом серия. Прогресс — `state/scenarios-v3/progress/*.jsonl`; снимки в git
  каждые 10–20 минут; ветка `claude/mitoderm-figma-catalog-74tbuw`, `git push -u origin`; без force-push; без
  идентификаторов модели в коммитах.
- Интерактивные вызовы MCP (`show_*`, виджеты) в агентах не делать — виснут на часы. Списки моделей и баланс снимать
  один раз и класть в файл.
- Диск Mac: `df -h .` до и после; не ставить Playwright/Chromium/LibreOffice; тяжёлые проверки — в облаке.
- Ключи только в переменных окружения (`ATLASCLOUD_API_KEY` и др.); в файлы, коммиты и ответы не попадают.
- Файлы для заказчика — целиком на иврите; перед отправкой проверить кириллицу.

## Как платить за Claude токенами, а не лимитом подписки
- **Cursor:** в настройках моделей включить модели Claude (последние Sonnet/Opus), оплата через Cursor. Правила
  проекта подхватываются автоматически из `.cursor/rules/mitoderm.mdc` и `AGENTS.md`; начинать с этого файла.
- **Claude Code локально:** `npm i -g @anthropic-ai/claude-code`, ключ с console.anthropic.com в переменной
  `ANTHROPIC_API_KEY`, запуск `claude` в корне репозитория — подхватит `CLAUDE.md` и `.claude/skills/` сам; оплата по
  API за токены, без недельного лимита подписки.
