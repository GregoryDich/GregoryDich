# Тестовая копия сайта (статическая)

`site/` — снимок кино-версии сайта из `codex-site`: готовые HTML-страницы и собранные скрипты со стилями.
Картинки и шрифты сюда не копируются: при выкладке под тот же корень кладётся `codex-site/public`.
Фильмы грузятся со своих адресов (`codex-site/mitoderm/media-urls.json`).

- Собрать заново: поднять тестовую версию (`pnpm build && pnpm start` в `codex-site`) и запустить
  `bash mitoderm-catalog/state/tasks/static-snapshot.sh`.
- Что не работает в копии: форма заявки (сервера и базы нет) — это намеренно, тестовая копия заявок не собирает.
- Переходы между страницами идут обычной загрузкой страницы.
- Копия закрыта от поисковиков: в ней лежит `robots.txt` с `Disallow: /`, а страницы называют каноническим адрес
  живого сайта. Свой `robots.txt` и карту сайта отдаёт только живой сайт (`codex-site/app/robots.ts`, `sitemap.ts`).
- Проверка копии: раздать папку (`python3 -m http.server 8799`) и запустить
  `python3 mitoderm-catalog/state/tasks/site-qa.py http://127.0.0.1:8799` — должно быть 0 замечаний.
- Живой сайт эта папка не трогает.
