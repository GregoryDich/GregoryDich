# Дополнение (15/08/2026, проход 2): сверка «весь ли оригинальный текст влез» + правки дизайна

## Метод
30 параллельных прогонов: в каждый вшиты эталонные строки исходника соответствующей
страницы; текст выгружен из Figma, обе стороны нормализованы (убраны только невидимые
bidi-маркеры, типографские кавычки, схлопнуты пробелы), проверено вхождение каждой
строки; развороты (06+06B, 07+07B, 10+10B, 12+13, 20+20B, 22+22B) сверялись объединением.

(единственное исключение — обрезанный WhatsApp'ом хвост стр. 21, ждёт пользователя).
