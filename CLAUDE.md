# MITODERM — правила проекта для любой сессии (облако или Remote Control)

Работа идёт по `mitoderm-catalog/PLAN.md` (что сделано и что дальше) и
`mitoderm-catalog/design-rules.md` (правила вёрстки, сайта v2, палитры). Читать их перед началом.

- **Образец перед серией.** Два и больше кадра, клипа или однотипных страниц — сначала один
  образец, показать заказчику, дождаться «ок». Платная генерация без «ок» не запускается.
- **Деньги.** Перед каждой генерацией — цена и баланс; трата только после «утверждаю».
- **Диск заказчика.** На его компьютере свободно около 2 ГБ. В локальной сессии: `df -h .` до и
  после работы, не больше 300 МБ сверх репозитория, тяжёлое не ставить (Playwright/Chromium,
  LibreOffice) — проверка страниц делается в облачной сессии; временные файлы удалять.
- **Ключи.** Только в переменных окружения (`ATLASCLOUD_API_KEY` и др.; `.mcp.json` ссылается
  на `${…}`). В файлы, коммиты, логи и ответы ключи не попадают. Репозиторий публичный.
- **Не в репозиторий:** прайсы, фото с людьми, `clip.mp4` переходов (в git идут только WebP-кадры).
- **Git.** Ветка `claude/mitoderm-figma-catalog-74tbuw`, `git push -u origin`; без
  идентификаторов модели в коммитах.
