## КРИТИЧЕСКАЯ НАХОДКА ДЛЯ H1

> **HBR (конец 2025):** Опрос руководителей показал, что большинство компаний, увольняющих «ради ИИ», основывают решение на **ожидаемом потенциале** ИИ, **а не на его доказанной производительности.**

Это БУКВАЛЬНО наша H1: нарратив ведёт фундаментал. Компании действуют на основе истории («ИИ скоро сможет»), а не на основе измеренного результата («ИИ уже делает»). Этот факт:
- **Валидирует** направление нашего исследования.
- **Создаёт приоритетную угрозу** — кто-то может формализовать это раньше нас.
- **Даёт нам готовую цитату** для введения.

## СТРУКТУРА ДЛЯ АНАЛИЗА

Каждый шок характеризуется:
1. **Дата** (точная, для временного ряда)
2. **Тип:** технологический / трудовой / медийный / регуляторный / финансовый
3. **Экзогенность:** высокая (не вызван экономическим спадом) / средняя / низкая
4. **Медиа-интенсивность:** измеряется через GDELT/Google Trends/YouTube
5. **Профессиональный охват:** какие профессии затронуты (для DiD по экспозиции)
6. **Поведенческий след:** есть ли измеримая реакция в данных
