Как сделано (все шаги офлайн; в движке — только drawImage, без ctx.filter и чтения пикселей):
  • вырезка: rembg isnet-general-use без alpha matting + кривая альфы; кромка уточнена ключом
    (по белому фону студии — звезда и краб; «жёлтое против сине-бирюзового» — губки);
    щупальца актинии — отдельный ключ «тонкая светлая структура на тёмной воде»: фон = морфологическое
    открытие (тонкие линии исчезают, широкие стебли травы остаются), альфа = проекция (цвет − фон) на
    (цвет щупальца − фон), цвет «размешан» от фона; трубка — ручной контур; соседняя актиния, морской
    конёк и песок исключены. Кромка тел: 1 px эрозия + деконтаминация цвета (без ореола).
  • под фото: ~1.5× размера в пикселях задника; баланс белого к нейтрали песка задника (163,215,237)
    в силе 70%; локальные чёрная/белая точки (5/95 перцентили в радиусе 200 px места установки) в силе
    60%; свет сверху (×1.06–1.08 → ×0.78–0.84); затемнённое основание у песка; мягкое плечо светов.
  • актиния: два слоя одного кадра — задний (anemone.png) и передний (anemone_front.png: щупальца,
    свисающие под диском); рыбы-клоуны рисуются между ними. Без рыбы back+front == цельная актиния
    (a_f = a·m, a_b = a·(1−m)/(1−a·m)). Трубка «утоплена» в песок, линия песка неровная.
  • губки: большая труба с чашами у основания (как в кадре) + вторая труба позади (та же, отражённая,
    ×0.70, темнее и холоднее); основания — дугами (цилиндр на песке).
  • краб: сжат по вертикали ×0.72 (взгляд с уровня песка); клешни вырезаны отдельно (тот же кадр) —
    для «ковыряния» поворотом вокруг шарнира; при угле 0 тело+клешни == crab.png.
  • звезда: повёрнута, чтобы стоять на двух лучах; ×0.90 по вертикали.

Пересборка — скрипты этапа A1 (вне репозитория, папка work/a1 рабочей области агента):

ГЕОМЕТРИЯ СЦЕНЫ — этап A2, 2026-10-16
======================================
Файлы: scene.js (разделы depthGrid, floor, light, occluders, patches, spots, bubbles; props — A1),
occ_mound.png, occ_front_frags.png (окклюдеры), patch_white_anemone.png, patch_pink_anemone.png,
patch_frogspawn.png (качающиеся участки), light_mask.png (маска каустики), ретушь в ../assets/reef_bg.jpg.

  • Задник: грейд A0 пересобран детерминированно (тот же md5), ретушь сделана по lossless-версии и закодирована
    ОДИН раз с параметрами A0 (q88, 4:4:4, progressive, optimize): блоки JPEG вне ретуши бит-в-бит прежние.
    Ретушь (гармоническая заливка фоном + зерно σ≈1) — только узкие полоски у кромок патчей без «поля воды»,
    которые качание может открыть (≈11 тыс. пикселей); остальной коралл остаётся в заднике.
  • Патчи — кропы задника ДО ретуши (исходный вид) с непрозрачным полем однородной тёмной воды вокруг
    (≥ 1.25·amp·S + 3 px); маска — порог по каналу (R для актиний, G для эуфиллии) в ручном полигоне,
    замыкание, заливка дыр; численная проверка при ±1.25·amp: 0 видимых пикселей исходного коралла.
  • Окклюдеры — кропы ИТОГОВОГО задника (декод PIL = декод Chromium, 1:1 max 1/255): маска холма — порог
    max(R,G,B) > 97 (тёмная вода ≈ 86±3) в ручном полигоне (исключены размытые синие объекты фона, левая
    колонна, розовая пластина), затенённые низы голов аканов добавлены полигонами; альфа = 1 ещё 2 px за
    силуэтом (в воде), спад 1.5 px; на разрезах полигоном — пологий спад ±3 px. Кропы выровнены под мип-сетку
    (начало и ширина кратны 32, высота ≡ 1355 mod 32).
  • Сетка глубины 32×17 — размечена по областям с опорой на «задранные» тени исходника (тёмное слева —
    каменная колонна, справа — скальная стена; открытая вода — центральный просвет и вода за верхом холма),
    холм — 1.06 спереди → 1.45 у верха, песок — по полу камеры; значение ячейки — 30-й перцентиль.
  • Маска света (640×339, альфа): песок ниже линии пола = 1; камень/кораллы = освещённость × «грань вверх».
  • Точки поведения, источники пузырьков и света — комментарии разделов в scene.js; наложения для проверки —
    на 4 соотношениях сторон (1.54, 1.6, 1.78, 2.33).

Как сделано (все шаги офлайн; в движке — только drawImage/композиты, без ctx.filter и чтения пикселей):
  • грубая маска — rembg (isnet-general-use и/или birefnet-general, без alpha matting), затем уточнение кромки ключом
    «проекция на F−B»: B — локальное среднее уверенного фона (вода/чёрный/тёмный риф по цвету), F — локальное среднее
    уверенного коралла; альфа = проекция (C−B) на (F−B); цвет кромки «размешан» F = B + (C−B)/α и деконтаминирован к цвету
    тела рядом — без ореола воды/чёрного фона ни на светлой, ни на тёмной воде;
  • веера — один общий ключ «веер против воды» по всему кадру (тонкие веточки 1–3 px сохраняют мягкую альфу); соседний
    веер — цветовым затвором «краснота»; рыбы-антиасы на веерах заменены соседним участком той же текстуры (клон-заплатки);
  • соседи, рыбы, камни — полигонами; края, закрытые в кадре соседями, мягко затухают в контактную тень (поле fade);
  • уменьшение — LANCZOS с премультипликацией (длинная сторона ≤ 1200 px), рамка 2 px — строго α = 0;
  • ДНЕВНОЙ грейд в линейном свете: баланс к нейтральному дневному свету, LED-оттенки (UV-синий, «кислотный» пурпур, голубой
    каст) переведены в пастельные природные (кремовый, бежево-лиловый, пыльно-розовый), насыщенность 0.55–0.9, лёгкая
    бирюза в тенях, свет сверху ×1.06–1.10 → ×0.78–0.84, затемнение основания, мягкое плечо светов. НОЧЬ — в движке.
