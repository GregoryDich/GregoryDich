# 🐠 Морской аквариум — живая заставка для macOS

Анимированный аквариум в духе **Living Marine Aquarium 2**: плавающие рыбки
разных видов, пузырьки, колышущиеся водоросли, кораллы и солнечные лучи в воде.

Это **один самодостаточный файл** (`index.html`) на HTML5 Canvas — без установки,
без зависимостей, работает офлайн. Его можно использовать тремя способами:
как обои рабочего стола (рыбки за иконками), как настоящую заставку или просто
открыть на весь экран.

**Палитра подобрана под оригинал** (тёплый насыщенный риф на холодной тропической
голубой воде) — разбор цветов в [`PALETTE.md`](PALETTE.md). Для **буквальных 100%**
по фону можно положить оригинальный кадр в папку `assets/` — см. ниже.

---

## 🚀 Быстрый старт (5 секунд)

1. Дважды кликните по файлу **`index.html`** — он откроется в Safari/Chrome.
2. Нажмите клавишу **F** — аквариум развернётся на весь экран.
3. Чтобы выйти — **Esc**.

Готово, рыбки уже плавают 🐠

### Управление
| Клавиша / действие | Что делает |
|---|---|
| **F** | Полный экран вкл/выкл |
| **Пробел** | Пауза |
| **Клик мышью** | Покормить (рыбки подплывают к корму 🍤) |
| **+ / −** | Больше / меньше рыбок |

Подсказка и курсор сами прячутся через несколько секунд — как у настоящей заставки.

---

## 🎯 Сделать на 100% как оригинал (свой фон)

Встроенный риф нарисован с палитрой оригинала. Если нужны **буквальные 100%**
по цветам и контрасту фона — положите оригинальный кадр аквариума в папку
`aquarium/assets/` под именем `background.jpg` (или `.png`). Тогда он станет
фоном, а наши рыбки, пузырьки и лучи будут плавать поверх него.

Подробности и где взять картинку — в [`assets/README.txt`](assets/README.txt),
а разбор палитры оригинала — в [`PALETTE.md`](PALETTE.md).

> Совет: лучше брать горизонтальный кадр в хорошем разрешении и по возможности
> без рыб — тогда нарисованные рыбки не будут накладываться на анимированных.

## 🖼 Вариант 1 — живые обои (рыбки за иконками рабочего стола) — рекомендую

Это именно то, что делают приложения вроде *MyWallpaper* со скриншотов, только
бесплатно и с нашими рыбками. Понадобится бесплатная программа **Plash**
(значок в строке меню — тот самый «трей-значок»).

1. Установите **Plash** — бесплатно в Mac App Store:
   <https://apps.apple.com/app/plash/id1494023538>
   (или через Homebrew: `brew install --cask plash`).
2. Кликните по значку Plash в строке меню → **Open URL…**
3. Нажмите **Browse…** и выберите наш файл `index.html`
   (или вставьте путь вида `file:///Users/ВАШ_ЛОГИН/.../aquarium/index.html`).
4. Всё — аквариум стал живыми обоями. В меню Plash можно:
   - выбрать, на каком мониторе показывать;
   - **Browsing Mode** — кликать по рыбкам прямо на обоях (покормить);
   - **Launch at login** — запускать вместе с системой;
   - экономия батареи — Plash сам приглушает анимацию на батарее.

> Совет: если опубликовать файл на GitHub Pages (см. ниже), в Plash можно
> вставить просто ссылку — и обои будут работать на любом Маке без копирования файла.

## 🌊 Вариант 2 — настоящая заставка (Screen Saver)

Чтобы аквариум включался по простою, как стандартная заставка macOS, используйте
бесплатный открытый **WebViewScreenSaver**:

1. Скачайте `.saver` из релизов проекта:
   <https://github.com/liquidx/webviewscreensaver>
2. Дважды кликните по скачанному файлу — macOS предложит установить заставку.
3. Откройте **Системные настройки → Заставка**, выберите *WebViewScreenSaver*.
4. В его настройках укажите адрес нашего файла:
   `file:///Users/ВАШ_ЛОГИН/.../aquarium/index.html`
   (или ссылку на GitHub Pages).

> На свежих macOS система может предупредить, что заставка от стороннего
> разработчика — разрешите её в **Системные настройки → Конфиденциальность и
> безопасность**.

## 🖥 Вариант 3 — просто на весь экран

Никаких программ не нужно: откройте `index.html` в браузере и нажмите **F**.
Удобно включить «не выключать дисплей» в настройках энергосбережения, если хотите,
чтобы картинка не гасла.

## 🌐 (необязательно) Опубликовать через GitHub Pages

Файл лежит в вашем профильном репозитории, поэтому его легко выложить в интернет:

1. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)`, **Save**.
2. Через минуту аквариум будет доступен по адресу:
   **`https://gregorydich.github.io/aquarium/`**
3. Этот адрес можно вставить в Plash или WebViewScreenSaver — и всё работает
   на любом устройстве, без копирования файлов.

## ⚙️ Как настроить под себя

Всё живёт в `index.html`, менять можно прямо в нём:

- **Виды и цвета рыб** — массив `SPECIES` (поля `main`, `back`, `belly`, `tail`,
  `bands` для полосок). Добавьте свой объект — появится новый вид.
- **Сколько рыб по умолчанию** — функция `targetFishCount()` (или просто `+/−`
  во время работы).
- **Скорость / размер** — параметры `base` и `len` в `makeFish()`.
- **Густота пузырьков** — `bubbleTimer` в главном цикле.
- **Водоросли и кораллы** — функция `buildScenery()`.

## Почему так, а не нативное приложение / `.exe`

Windows-заставка из vsthemes — это `.scr` под Windows, на macOS она не запускается.
Под Mac «правильная» заставка — это `.saver` (Swift/Xcode) с подписью кода, что
требует сборки и возни с безопасностью. Подход «один HTML-файл + Plash/WebViewScreenSaver»
даёт тот же результат — плавающих рыбок на рабочем столе или в заставке — но
работает сразу, без Xcode и без установки тяжёлых программ.
