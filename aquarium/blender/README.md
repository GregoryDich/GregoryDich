# Blender-пайплайн аквариума

Все «настоящие» картинки аквариума — рыбы и риф — **рендерятся Blender'ом (Cycles)
из процедурных моделей**, которые строят два скрипта. Ничего не скачивается и не
генерируется нейросетью: любую рыбу или коралл можно поправить в коде и
перерендерить, а `.blend` открыть в Blender и доделать руками.

| Скрипт | Что делает | Результат |
|---|---|---|
| `fish.py` | Параметрические рыбы: тело лофтом по аналитическому профилю, плавники, глаз; окрас печётся numpy'ем в текстуру (полосы, пятна, области, двуцветность) | `fish/<id>.png` — прозрачные спрайты носом вправо |
| `reef.py` | Процедурный риф: песок с каустикой, скальная стена, кораллы-мозговики, «капуста», ветвистые, плоские, губки, актинии, морская звезда, веера; туман по дальности | `assets/reef_bg.jpg` (задник) + `assets/reef_fg.png` (прозрачный передний план) |

Движок `index.html` рисует: задник → дальние рыбы → передний план → ближние рыбы
(`FG_SPLIT`), так что рыбы проплывают **за** ближними кораллами, как в LMA2.

## Установка
Blender как Python-модуль (нужен Python 3.11):

    pip install bpy numpy

Рендер на CPU. Ориентиры на 4 ядрах: рыба ≈ 1–3 мин (128 сэмплов, 1400 px),
риф ≈ 10–25 мин (1920 px, 96 сэмплов).

## Команды

    cd aquarium/blender
    python3 fish.py --out ../fish                        # все виды
    python3 fish.py --out ../fish --only clownfish,blue_tang --samples 64 --res 1000
    python3 fish.py --out ../fish --blend                # + .blend каждой рыбы
    python3 reef.py --out ../assets                      # риф в два слоя
    python3 reef.py --out /tmp/x --preview               # быстрая проверка

## Как добавить / поправить рыбу
В `fish.py` словарь `SPECIES`: тип тела (`oval`/`disc`/`round`/`small`), цвета
спины/брюха, список узоров и плавники. Узоры:

    ('bands', [v...], width, color, edge|None, edge_w)   # поперечные полосы (v: 0 хвост … 1 нос)
    ('hstripes', count, width, color)                     # продольные полосы
    ('spots', n, r, color, 'lower'|'upper'|'all', seed)   # пятна
    ('ellipse', cv, ct, rv, rt, color, soft)              # органичное пятно (t: 0 брюхо … 1 спина)
    ('region', v0, v1, t0, t1, color, soft)               # прямоугольная область
    ('bicolor', split, color, soft, slant, 'rear'|'front')
    ('wavy', count, width, color, edge, amp)              # волнистые полосы (мандаринка)

Добавили запись — добавьте её же `id` в `../fish/manifest.js` (имя, размер, количество).
