# 🎨 Анализ палитры оригинала — Living Marine Aquarium 2

Цель: воспроизвести ощущение оригинала через **контраст, цвета и оттенки**.
Главный приём, создающий «ту самую» ностальгию — **тёплый риф на фоне холодной
воды** (комплементарный контраст тёпло/холодно). Вода — яркая тропическая
сине‑голубая (НЕ тёмно‑синяя), риф — насыщенный, тёплый, с пурпурно‑фиолетовыми
акцентами. Картинка светлая и контрастная, мягкие лучи света сверху.

> Значения подобраны визуально по эталонному кадру (точную попиксельную выборку
> сделать в этой среде нельзя — нет доступа к файлу). Для буквальных 100% можно
> положить оригинальное изображение в `assets/` — см. README.

## Вода (вертикальный градиент сверху вниз)
| Позиция | Цвет | Характер |
|---|---|---|
| верх (0%) | `#18639b` | насыщенный океанский синий |
| ~30% | `#2a86bd` | светлее, проникает свет |
| солнечное пятно (вверху‑центр) | `#7fccea` → прозрачн. | радиальный блик от поверхности |
| у линии рифа (~62%) | `#3f9ac4` | светлее/«дымка» от глубины |

Холодная палитра воды — голубо‑циановая, средней светлоты. Это база контраста.

## Свет
- Мягкие широкие «лучи Бога» сверху, чуть наклонные, бледно‑голубо‑белые
  `rgba(190,235,255,~0.08)`. Тонкие, не кричащие.
- Лёгкая горизонтальная дымка у линии рифа (рассеяние в воде).

## Песок
Зеленовато‑песочный, освещён в центре:
`#c7c389` (свет) → `#bdb277` → `#a08f5e` (тень), зеленоватый подсвет по центру.

## Элементы рифа (тёплая, насыщенная часть — «жар» картинки)
| Элемент | Базовый цвет | Заметки |
|---|---|---|
| Жёлтый мягкий коралл (слева/справа) | `#ffd21a` | очень яркий, с зеленовато‑жёлтыми кончиками |
| Оранжевая губка | `#e8631a` | тёплый акцент |
| Тан/персиковые трубчатые губки (центр/справа, высокие) | `#cf9a5c` | объёмные «трубы», тёмные устья |
| Розоватая трубчатая губка (центр) | `#d18a82` | |
| Бело‑серый ветвистый коралл (стэгхорн) | `#dcdcce` | светлый, контраст к тёплым |
| Пурпурно‑розовый коралл (справа) | `#ef5fa0` | насыщенный розовый |
| Фиолетовый морской веер | `#8a5fbf` | ажурный, чуть колышется |
| Красная морская звезда (на песке справа) | `#d8392a` | яркий тёплый акцент внизу |
| Синий/фиолетовый коралл (база справа) | `#5a6fd0` | холодный акцент |
| Камни/скалы (основание) | `#5e472d` | приглушённый коричневый, держит композицию |
| Зелёные водоросли/тёрф | `#5fae5a` | вертикальные колышущиеся ленты |
| Розовая актиния (центр) | `#e58aa0` | колышущиеся щупальца — добавляет «жизнь» |

Композиция слева→направо (как в оригинале): жёлтый+оранжевый слева → розовая
губка и белый коралл в центре с актинией → высокие тановые трубы → справа
пурпурный коралл, фиолетовый веер, синий коралл и красная звезда на песке.

| Вид | Тело | Детали |

## Контраст / общий характер
- **Высокая насыщенность**, светлая средняя яркость (картинка не тёмная).
- **Тёпло/холодно**: тёплый риф (жёлтый/оранж/розовый/красный) ↔ холодная
  голубая вода — главный драйвер ностальгии.
- Рыбы — чёткие, с тёмным глазом и лёгким контуром, хорошо читаются на воде.
- Лёгкая виньетка по краям, но в целом ярко и «прозрачно».
