# 🐠 AquariumWallpaper — живые обои для macOS

Нативное приложение: рыбки плавают **на рабочем столе, за иконками** — как у того
приложения из App Store, но с нашим аквариумом. Это **значок в строке меню** (трей)
+ невидимое окно-обои на каждом мониторе. **Без меню паузы/настроек** — только
«Запускать при входе» и «Выход».

- Цель: **MacBook M4 Pro, 4K**, Retina-чёткость.
- Оптимизация: 60 fps от сети, **30 fps от батареи**, **пауза при засыпании дисплея**.
- Движок — наш `../aquarium/` (встраивается в .app), рыбы берутся из `fish/`.

## Сборка (Terminal, Xcode Command Line Tools должны стоять)

```bash
cd macos-app
chmod +x build.sh
./build.sh --run
```

Появится значок рыбки 🐟 в строке меню, аквариум станет фоном рабочего стола.

## Подпись вашим Apple Developer ID

```bash
# посмотреть доступные сертификаты:
security find-identity -v -p codesigning
# собрать и подписать:
./build.sh --sign "Developer ID Application: ВАШЕ ИМЯ (XXXXXXXXXX)"
```

Так Gatekeeper не будет ругаться на «неизвестного разработчика». Без подписи
первый запуск: **ПКМ по .app → «Открыть»**, либо *Системные настройки →
Конфиденциальность и безопасность → Открыть всё равно*.

## Как это работает (коротко)
- `main.swift` — агент в строке меню (`.accessory`, без иконки в Dock).
- `WallpaperWindow.swift` — borderless-окно на уровне `desktopWindow` (выше
  картинки рабочего стола, ниже иконок), `canJoinAllSpaces` + `stationary`,
  `ignoresMouseEvents` (клики проходят к иконкам). Внутри — `WKWebView` с
  аквариумом в режиме обоев (`window.__WALLPAPER = true`).
- `AppDelegate.swift` — по одному окну на каждый экран, слежение за подключением
  мониторов, сном дисплея и питанием; шлёт в страницу `aquariumSetPower(...)`.

## Рыбы в высоком качестве
Аквариум уже работает с векторными рыбками. Чтобы заменить их на реалистичные:
положите прозрачные PNG в `../aquarium/fish/` (имена и промпты — в
`../aquarium/fish/PROMPTS.md`). Приложение подхватит их при следующем запуске.

## Если что-то не так
- **Обои поверх иконок / не видно** — поменяйте уровень окна в
  `WallpaperWindow.swift`: вместо `.desktopWindow` попробуйте
  `CGWindowLevelForKey(.desktopIconWindow) - 1`.
- **Несколько мониторов** — окно создаётся на каждый, пересоздаётся при
  изменении конфигурации экранов автоматически.
- **Полностью выключить** — значок в строке меню → «Выход».

> Хотите максимально нативно (SpriteKit/Metal вместо WebView) ради ещё меньшего
> энергопотребления — это следующий шаг; текущий вариант уже лёгкий и
> аппаратно-ускоренный на M-чипах.
